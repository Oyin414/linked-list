# About Linked-Lists

This Linked List project is a good way for me to practice writing a linked list and writing the different methods associated with a linked list.A linked list is a data structure similar to an array but you can only traverse through the head node.

## How It's Made:

**Tech used:** JavaScript,webpack,jest

This project uses jest tests to make sure the methods written in my linked list class were working as designed.

## Lessons Learned:

During this project my main goal was to learn how to use linked lists as it's a great alternative to an array and is one of the most fundamental data structures in computer science. Over the course of building this project I learnt how to traverse a linked list and how to remove and add nodes onto a linked list.
